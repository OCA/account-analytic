The goal of this module is to ease analytic distribution management on purchase blanket order.
This module add analytic distribution on purchase blanket order.

If all lines of the purchase blanket order have the same analytic distribution, the analytic distribution on the purchase blanket order is automatically set with this value.
If a analytic distribution is set on the purchase blanket order, all lines of the blanket order will take this value.
