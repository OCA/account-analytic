This module improves the usability and accessibility of Analytic Items
(analytic lines) in Odoo:

- Adds an option to export selected analytic lines directly from the
  list view.
- Provides a direct link to the related Journal Entry for each analytic
  line.
- Sets a default Group By (Financial Account) for easier data analysis.
- Optimizes the menu sequence for Analytic Items in the Accounting app.
- Enhances data integrity by making the Analytic Items list view
  read-only.

Usage
=====

This module improves the usability of **Analytic Items** in Odoo.

To use the features:

1. Go to **Accounting → Analytic → Analytic Items**.
2. View records grouped by **Financial Account** by default.
3. Select one or multiple records and use the **Export** option to
   export data.
4. Open any Analytic Item to access the **linked Journal Entry** using
   the provided button.
5. Note that the list view is **read-only**, so records cannot be edited
   inline.
