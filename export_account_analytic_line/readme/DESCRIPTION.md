This module improves the usability and accessibility of Analytic Items (analytic lines) in Odoo:

- Adds an option to export selected analytic lines directly from the list view.
- Provides a direct link to the related Journal Entry for each analytic line.
- Sets a default Group By (Financial Account) for easier data analysis.
- Optimizes the menu sequence for Analytic Items in the Accounting app.
- Enhances data integrity by making the Analytic Items list view read-only.
