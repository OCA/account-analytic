This module improves the usability of **Analytic Items** in Odoo.

To use the features:

1. Go to **Accounting → Analytic → Analytic Items**.
2. View records grouped by **Financial Account** by default.
3. Select one or multiple records and use the **Export** option to export data.
4. Open any Analytic Item to access the **linked Journal Entry** using the provided button.
5. Note that the list view is **read-only**, so records cannot be edited inline.
