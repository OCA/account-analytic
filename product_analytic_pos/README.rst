This module applies analytic distribution models defined on products or
product categories to uninvoiced POS sales when the POS session is
closed.

If several POS order lines resolve to different analytic distributions,
the closing entry is split so each generated account move line keeps its
own analytic distribution.

Usage
=====

To use this module:

1. Configure analytic distribution models on products or product
   categories.
2. Create POS orders without invoices in a POS session.
3. Close the POS session.
4. Review the generated sales journal entry lines in the session closing
   move.

When different products or product categories resolve to different
analytic distributions, the session closing move is split accordingly
and each sales line keeps the expected analytic distribution.
