This module adds the **Commercial Entity** field (technical name
commercial_partner_id) to analytic items and allows users to group
*Analytic items* by this field.

**Table of contents**

.. contents::
   :local:

Usage
=====

1. Go to Invoicing > Accounting > Analytic Items
2. Group *Analytic items* by **Commercial Entity**
