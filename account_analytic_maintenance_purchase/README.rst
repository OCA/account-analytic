This module propagates the analytic distribution from purchase order
lines to maintenance equipment created by the maintenance_purchase
module.

**Table of contents**

.. contents::
   :local:

Usage
=====

Go to *Purchase > Orders*. Create a purchase order with one or more
lines having an analytic distribution. Set an equipment category on the
purchase order line. Confirm and approve the purchase order Open the
generated maintenance equipment. Verify that the analytic distribution
has been propagated from the purchase order line
