1.  Go to Sales \> Orders \> Quotations and open or create a quotation.
2.  Set the analytic distribution in the field next to the customer.
    All order lines take this distribution, and new lines get it by
    default. Sections and notes are ignored.
3.  Change the analytic distribution of a line if that line needs a
    different one.

When all order lines have the same analytic distribution, the order
shows this distribution.

When the order lines have different analytic distributions, the field
on the order is empty. Each line keeps its own distribution. If you then
set a distribution on the order, it replaces the distribution of all
lines.

If you clear the analytic distribution of the order, the lines keep
their distribution.
