This module adds an analytic distribution on payments. When the payment
is posted, that distribution is propagated to the counterpart journal
item (the receivable/payable line), so the analytic information is
available on the accounting entry.

.. contents::
   :local:

Usage
=====

1. Go to Accounting > Customers > Payments (or Vendors > Payments), or
   register a payment from an invoice/bill.
2. Set the *Analytic Distribution* (available on the payment and on the
   register payment wizard).
3. Confirm the payment.
4. Open the related journal entry: the counterpart line
   (receivable/payable account) carries the analytic distribution set on
   the payment.
